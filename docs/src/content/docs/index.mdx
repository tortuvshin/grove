## What is Grove?

Grove packages a coherent, opinionated set of building blocks for product
documentation sites built on [Astro Starlight](https://starlight.astro.build).
Stop rewriting the same sidebar, theme, and content scaffolding for every
project — plant a Grove instead.

<CardGrid stagger>
	<Card title="Garden" icon="seti:notebook">
		Plant a content collection once and reuse it across every framework
		adapter. Sidebar, page title, search, and hero layout are already wired
		up — focus on the words, not the chrome.
	</Card>
	<Card title="Grow" icon="rocket">
		Drop a new framework adapter into the workspace and Grove picks it up.
		Next.js, Svelte, Astro, and Starlight all share the same content tree
		and the same look.
	</Card>
	<Card title="Maintain" icon="setting">
		Tokens, type-safety, and versioning are first-class. Bump a content
		schema, theme token, or component once — every consumer site updates on
		the next install.
	</Card>
	<Card title="Splash pages" icon="open-book">
		Hero layouts, card grids, link cards, and badge variants are tuned for
		landing pages, changelogs, and reference indexes. Just author the
		content.
	</Card>
</CardGrid>

## The Grove workflow

<CardGrid>
	<Card title="1. Plant" icon="pencil">
		Author your content in MDX under a single content collection. Frontmatter
		extends the Starlight schema with announcement, hero layout, and link
		attributes.
	</Card>
	<Card title="2. Pick a frame" icon="list-format">
		Choose a framework adapter — Astro, Next.js, Svelte, or Starlight — and
		Grove keeps the sidebar, hero, and theme in sync across all of them.
	</Card>
	<Card title="3. Ship" icon="rocket">
		Run `grove build` and publish. The output is a normal Starlight site, so
		hosting on Vercel, Netlify, Cloudflare, or GitHub Pages just works.
	</Card>
</CardGrid>
