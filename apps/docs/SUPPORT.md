# Support

This page is the in-docs version of [`.github/SUPPORT.md`](../../.github/SUPPORT.md) — the same rules, framed for someone reading the docs site rather than the GitHub repo.

| Question type | Channel |
| --- | --- |

| "I found a security issue" | **Email** toroo.byamba@gmail.com — see [`SECURITY.md`](../../SECURITY.md). Do **not** file a public issue. |
| "I need enterprise / paid help" | Open a discussion — there's no paid support tier. |

## Maintainer response time

Grove is a small, part-time project. The targets are:

- **Issues** — first reply within 3 working days; triage label within 7 days.
- **Security reports** — acknowledgement within 72 hours; triage within 7 days; fix ASAP, coordinated with the reporter.
- **Discussions** — best-effort. There's no SLA, but most threads get a same-week reply.

If your issue is blocking you and the maintainers are quiet, the practical answer is usually "open a draft PR" — the maintainers are much faster to react to code than to prose.

## Commercial / paid support

There is no paid support tier, no private Discord, and no SLA. Grove is MIT-licensed community software, intentionally.

If you want custom adapter work, a migration from a different directory / wiki / Notion setup, or hands-on help integrating Grove into a larger org, open a discussion describing the scope and we'll see what we can do.

## Code of conduct

All community spaces follow [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md). Be kind, assume good faith, and steer technical disagreement back to the technical facts.
