<Aside type="tip" title="Netlify as a deploy target">
  Netlify shines for static sites with PR previews, branch deploys, and edge functions. No Astro adapter is required for fully static Grove spaces — the build output in `dist/` is the default publish directory.
</Aside>

Grove spaces deploy to Netlify with no adapter required. Astro's static output (`dist/`) is the default Netlify publish directory.

<Aside type="note" title="Prerequisites">
  - A Netlify account (the free tier works).
  - A Grove space that builds to `dist/` via `pnpm build`.
  - Node 24 (set via `NODE_VERSION=24` env var or `netlify.toml`).
  - Optional: a custom domain you control for production hosting.
</Aside>

## Configuration

`netlify.toml` at the project root:

```toml title="netlify.toml"
[build]
  command = "pnpm exec grove check && pnpm build"
  publish = "dist"

[[headers]]
  for = "/*"
  [headers.values]
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```

The `grove check` command validates config and emits `data/generated/*.json`, sitemap, llms files, robots, and og-image before the build runs.

## Build settings

<Steps>

1. **Build command:** `pnpm exec grove check && pnpm build`
2. **Publish directory:** `dist`
3. **Node version:** 24 (set via `NODE_VERSION=24` env var or `netlify.toml`)

   <Aside type="note" title="What you should see">
     Netlify's build log shows `grove check` running first (emitting `data/generated/*.json`, sitemap, llms, robots, og-image) before `astro build` produces `dist/`.
   </Aside>

</Steps>

## Custom domain

<Steps>

1. Add the domain in the Netlify admin panel.
2. Update `site.url` in `grove.config.ts` to match.

</Steps>

<Aside type="note" title="What you should see">
  Netlify issues a Let's Encrypt certificate automatically once DNS points at the assigned hostname.
</Aside>

## Headers and redirects

Use `_headers` and `_redirects` in `public/` for static rules, or `netlify.toml` for build-time configuration.

## Edge functions

Optional — Astro's `output: 'hybrid'` mode allows per-route SSR via Netlify Edge Functions. Most Grove spaces don't need this.
