The fastest path to a working Grove site — five commands, minimal explanation. For the full walkthrough, with what each step does and why, see [Getting started](/getting-started/scaffold/).

## Prerequisites

<Aside type="note" title="Before you begin">
  - Node `>=22.12.0`
  - pnpm, npm, yarn or bun — whichever you already use. The commands below are written for pnpm; swap `pnpm dlx` for `npx` or `bunx` and `pnpm` for `npm run`/`bun run`. `grove init` detects your choice and scaffolds for it.
</Aside>

<Steps>

1. ## Scaffold a space

   ```bash
   pnpm dlx @grove-dev/cli@latest init my-space
   cd my-space
   ```

2. ## Start the dev server

   ```bash
   pnpm dev
   ```

   Open `http://localhost:4321` — the site renders with one sample record, `content/records/grove.md`. Open it to see the shape of a record; delete it once you have your own.

3. ## Add your first record

   Create a Markdown file under `content/records/`. The filename is the slug; the fields go in the frontmatter and your notes go underneath:

   ```markdown title="content/records/my-project.md"
   ---
   name: My Project
   description: One-line summary of what my-project does.
   repoUrl: https://github.com/me/my-project
   stack: typescript
   licenses: [mit]
   ---

   Why this project is on the list.
   ```

   See [Add your first record](/getting-started/first-record/) for the full field reference.

4. ## Validate and build

   ```bash
   pnpm exec grove check
   pnpm build
   ```

   The deployable site is in `dist/`. Any static host serves it.

5. ## Deploy

   ```bash
   pnpm build && pnpm preview
   ```

   Preview the production build locally, then follow the [Deploy your site →](/deployment/overview/) guide — it covers GitHub Pages, Cloudflare, Netlify, and self-hosted setups.

</Steps>
