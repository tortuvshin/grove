The vocabulary used throughout the Grove docs. Use these words with the meanings given below — synonyms and older terms are deliberately not preserved.

<Aside type="note" title="How to use this glossary">
This page is the single source of truth for Grove terminology. When a term first appears elsewhere in the docs it links here. The terms are grouped by the part of the system they describe: records, taxonomy, curation, outputs, health, and build. Each card lists the terms in that area with the canonical definition — read straight through once, then keep it open as a reference.
</Aside>

## Source files

<CardGrid>
  <Card title="Records" icon="seti:notebook">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **record** | One typed entity in a Grove space, stored as a single YAML file under `data/records/<slug>.yml`. The filename minus `.yml` is the slug. |
    | **kind** | The discriminator on a record: `project`, `resource`, or `entity`. One kind per blueprint. |
    | **blueprint** | A schema family set in `grove.config.ts` as a flat string: `project-directory`, `resource-hub`, or `ecosystem-map`. No init-time choice; `grove init` always scaffolds `project-directory`. |
  </Card>

  <Card title="Taxonomy" icon="list-format">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **taxonomy** | A controlled vocabulary in `data/taxonomy/<name>.yml`. Six files: `categories.yml`, `stacks.yml`, `platforms.yml`, `licenses.yml`, `topics.yml`, `distribution-channels.yml`. Each entry has an `id:` and display fields. |
    | **facet** | A taxonomy dimension exposed in the browse UI. Canonical ids only: `category`, `stack`, `platform`, `tags`, `license`. |
  </Card>

  <Card title="Curation" icon="star">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **decision** | A curator override in `data/decisions.yml` keyed by record id. Changes visibility, sort priority, rename-slug, etc. |
    | **collection** | A grouping in `data/collections/<slug>.yml`, always a `query` + `ranking` pair. `kind` is `curated` or `generated` — both run the same query/ranking pipeline; `kind` only changes the page's eyebrow label. |
    | **lens** | An opinionated build-time view over the record set. 12 built-in lenses: `all`, `recently-updated`, `new`, `hot`, `mature`, `production-like`, `good-to-learn`, `beginner-friendly`, `contribution-ready`, `launches`, `actively-developed`, `needs-maintainer` (`packages/core/src/directory-lenses.ts:46`). Not the same as a curation label — `featured` is a label, not a lens. |
  </Card>
</CardGrid>

## Outputs

<CardGrid>
  <Card title="Outputs" icon="rocket">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **JSON dataset** | `data/generated/{records.full.json,records.index.json,records.json,site-config.json}`. Rewritten on every `grove check`. |
    | **OG card** | A satori-rendered PNG social image under `public/og/`, namespaced by page type: `home.png`, `default.png`, `records/<slug>.png`, `collections/<slug>.png`, `categories/<id>.png`, `stacks/<id>.png`, `licenses/<id>.png`. |
    | **OG SVG fallback** | `public/og-image.svg`. Sentinel-owned; editing it takes ownership and stops regeneration. |
    | **sitemap** | `public/sitemap.xml`. A single-file sitemap (no index file). |
    | **robots** | `public/robots.txt`. Sentinel-owned on first emission; user edits survive thereafter. |
    | **`llms.txt`** | `public/llms.txt` — constant-size site header (name, description, directory link, record/category counts). Carries no per-record content; see `llms-full.txt` for that. |
    | **`llms-full.txt`** | `public/llms-full.txt` — verbose form with full record descriptions. |
    | **README block** | The Markdown bounded by `<!-- grove-readme:start/end -->` in `README.md`, regenerated by `grove readme generate`. |
    | **`cleanup-report.json`** | Output of `grove cleanup`. Surfaces records flagged for human review. Never deletes records. |
    | **`contributors.json`** | Aggregated contributor counts from `grove sync contributors`. |
    | **icons** | `public/icons/**` — the packaged icon set from `@grove-dev/astro`. Edit-in-place per file. |
  </Card>
</CardGrid>

## Health & maintenance

<CardGrid>
  <Card title="Health & maintenance" icon="warning">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **status** | Top-level state on `project` records: `active`, `mature`, `stale`, `inactive`, `archived`, `unknown`, `historical`, `needs_review`, `quiet`, `unavailable`. |
    | **maturity** | `experimental`, `useful`, `mature`, `unknown`. |
    | **tier** | Curation tier: `curated`, `listed`, `experimental`, `hidden`. |
    | **visibility** | Curation visibility: `highlight`, `keep`, `needs_review`, `hide`, `remove`, `historical`. |
    | **cleanup candidate** | A record with `health.cleanupCandidate: true`. Surface for review via `cleanup-report.json`. |
    | **`integrations.github`** | A `grove.config.ts` boolean or `{ metadata, contributors, health }` partial object. Gates `grove sync github` and `grove sync contributors`. |
  </Card>
</CardGrid>

## Configuration & build

<CardGrid>
  <Card title="Configuration surfaces" icon="setting">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **`grove.config.ts`** | The site's configuration. Sets blueprint, site identity, nav, footer, browse facets, integrations, theme, audit pages. |
    | **`site.config.ts`** | The resolved `grove.config.ts` plus audit metadata, written to `data/generated/site-config.json`. |
  </Card>

  <Card title="Engineering" icon="document">
    <Badge text="term" variant="default" />

    | Term | Definition |
    |---|---|
    | **Astro integration** | `@grove-dev/astro`. Wires Vite aliases, runs `prepareDirectory()` on every dev/build, manages `public/icons/`, emits per-page OG/JSON-LD. |
    | **CLI** | `@grove-dev/cli`. The `grove` binary. Thin shell over `@grove-dev/core`. |
    | **Core** | `@grove-dev/core`. The framework-free engine: schemas, generators, validators, taxonomy, sitemap, llms, OG images, importers. |
    | **Page document** | `definePageDocument` from `@grove-dev/core`. Declares the SEO contract (title, description, canonical, OG, Twitter, JSON-LD) per page. |
  </Card>
</CardGrid>
