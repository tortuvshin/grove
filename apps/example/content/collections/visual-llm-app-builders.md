# Visual LLM App Builders

## How to choose

| | Dify | Flowise |
|---|---|---|
| Shape | Platform: editor, RAG, agent runtime, API | Builder: node editor plus a runtime |
| Deployment | Multi-service Docker stack | Single Node.js service |
| Best at | Shipping an internal LLM app end to end | Prototyping an agent flow quickly |

Start with [Flowise](/projects/flowise/) when you are exploring what a flow should look like. Move to [Dify](/projects/dify/) when the flow needs document retrieval, versioning and an API other systems call.

## Not listed and why

[CrewAI](/projects/crewai/) and LlamaIndex are frameworks you program against, not canvases — see [Top Open Source AI Agents](/collections/top-ai-agents/).
