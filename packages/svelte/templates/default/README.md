# Default template for the SvelteKit framework adapter.

> Reserved for V1.1. The V1 CLI refuses `--framework svelte` at scaffold time.

When V1.1 lands, the layout will be:

```txt
src/routes/                 SvelteKit file-based routes (list, detail, about, submit)
src/lib/components/         Reusable components (port of the 22 V1 Astro surface)
src/lib/data/               Generated by `grove generate` (records.full.json, records.index.json, site-config.json)
static/                     Static assets (icons, llms.txt, robots.txt)
svelte.config.js
tsconfig.json
```

The CLI will copy this directory verbatim into a new project via `grove new --framework svelte`. Pages and layouts live here; business logic lives in `@grove-dev/core` and `@grove-dev/ui` (V1: 5 typed primitives), and is imported into the template.

The template's `package.json` scripts chain the V1 CLI commands:

```jsonc
{
  "scripts": {
    "build:data": "grove generate",
    "build:sitemap": "grove sitemap",
    "build:llms": "grove llms",
    "build": "pnpm run build:data && pnpm run build:sitemap && pnpm run build:llms && vite build"
  }
}
```

V0 command names (`grove build-data`, `grove build-llms-full`, `grove analyze`, `grove enrich`) are not used. The V1 names are: `grove generate`, `grove llms`, `grove sync github`.
